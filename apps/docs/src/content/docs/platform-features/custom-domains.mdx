---
title: Custom Domains
description: Bind your own custom domains to local tunnels with automated SSL/TLS certificates.
---

Outpipe allows you to serve tunnels from your own branded domain names (e.g., `api.yourcompany.com` or `preview.internal.dev`) instead of default `*.outpipe.app` subdomains.

## Adding a Custom Domain

1. In the **Outpipe Dashboard**, navigate to **Domains**.
2. Enter your fully qualified domain name (e.g., `api.example.com`).
3. Choose a verification method: **DNS TXT**, **HTTP**, or **DNS automated**.
4. Outpipe generates a unique verification token for your domain.

## Manual Verification

### DNS TXT Record

Add a TXT record proving ownership:

- **Type**: `TXT`
- **Name**: `_outpipe-challenge.api.example.com` (shown as `_outpipe-challenge.<hostname>` in the dashboard)
- **Value**: the verification token shown after creating the domain

Then click **Verify** next to the domain and enter the token.

### HTTP Verification

Create the domain with the **HTTP** verification method, serve the challenge file at the requested path on your domain, then click **Verify**.

## Automated DNS Verification

For hands-free verification, connect a DNS provider first:

1. In the **DNS automation** section, select **Cloudflare**.
2. Paste a Cloudflare API token with the **Zone DNS edit** scope, plus a label, and click **Connect provider**.
3. Create the domain with the **DNS automated** verification method.

Outpipe publishes the `_outpipe-challenge.<hostname>` TXT record through the provider automatically, then verifies the domain. Provider tokens are write-only: the API never returns the raw token, and the dashboard only shows a masked suffix (`…lastFour`). Disconnect a credential at any time to revoke it.

### Wildcard Domains

Wildcard hostnames such as `*.example.com` require the **DNS automated** method — manual TXT and HTTP verification do not cover wildcards. Connect a Cloudflare token first, then create the wildcard domain.

## Automated SSL/TLS Certificates

Once verified, Outpipe automatically provisions and manages SSL/TLS certificates for the domain.

- **Automatic Renewal**: Certificates are renewed server-side starting 30 days before expiration.
- **Expiry Visibility**: The dashboard shows each domain's certificate expiry date.

## Removing a Domain

Click **Delete** next to a domain to remove it. Deleting a domain does not disconnect your DNS provider credentials.
